= User

== Overview

The User entity represents an individual user of the system. It contains information about their profiles and authentication credentials.

A User in this system can have one of two roles: `admin` or `member`. The role determines the level of access and permissions the user has within the system.

== Attributes

* `id` (string): A unique identifier for the user.
* `email` (string): The user's email address.
* `password` (string): The user's hashed password for authentication.
* `role` (string): The user's role, which can be either `admin` or `member`.
* `created_at` (datetime): The timestamp when the user account was created.
* `updated_at` (datetime): The timestamp when the user account was last updated.
